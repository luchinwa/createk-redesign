# Createk: прототип редизайна

Прототип нового сайта createk.pro. Страница закрыта от индексации (`noindex`).

**v3 (текущая):** во главе бренд MGP — погрузчики собственного производства (MG85PE, MGP 928 pro, MGP 946 pro) и фильтры, всё в наличии на складе в Краснодаре. Спецтехника: в наличии, под заказ, портфолио. Бренды-партнёры Createk, Forview, Impeco ниже. Поставки из Китая партиями — дополнительная услуга.

Модели, цены и характеристики — из КП ООО «ФавАвто Трейд». Фото техники — из архива клиента для примера. Логотип MGP перерисован условно.

## Как обновить GitHub Pages

1. В репозитории: **Add file → Upload files**.
2. Перетащить `index.html` и `README.md` из этой папки.
3. **Commit changes**, подождать 1–2 минуты, открыть сайт с Ctrl+F5.
4. Первый раз: **Settings → Pages → Branch: main, папка / (root) → Save**.
